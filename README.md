## Project Overview
Personal Expense Tracker is a command-line Python application for recording,
analyzing, and managing personal expenses and monthly budgets.

## Features
- Add expenses
- View all expenses
- Search expenses
- View spending by category
- Calculate total spending
- Set and update a monthly budget
- Check budget status
- Remove an expense

## Files
- `main.py` - Main application and user interaction
- `expense_manager.py` - Reusable expense-management functions
- `.gitignore` - Git configuration

## How to Run
```bash
python main.py
